## ✨ Features

### 👁️ ESP
- Player ESP
- Player Name
- Distance
- Survivor Detection
- Hunter Detection
- Player Filter
- Alive / Hunter Counter
- Freeze Detection

### 🎯 AIM
- Aim Assist
- Adjustable FOV
- Adjustable Smooth
- Target Selection
- Ignore Hunters
- Ignore Downed Players
