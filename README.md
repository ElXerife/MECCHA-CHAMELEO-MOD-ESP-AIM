## ✨ Features

### 👁️ ESP

- Player ESP
- Player Names
- Distance ESP
- Survivor Detection
- Hunter Detection
- Alive / Hunter Counter
- Player Filter
- Ignore Hunters
- Ignore Downed Players
- Target Highlight
- Freeze Detection

### 🎯 AIM

- Aim Assist
- Adjustable FOV
- Adjustable Smooth
- Target Selection
- Player Filter
- Ignore Hunters
- Ignore Downed Players
- Target Indicator

## 🚀 Como usar

1. Abra **MECCHA CHAMELEON**
2. Execute o **MECCHA ESP & AIM**
3. Faça login com sua licença
4. Configure o **ESP**
5. Configure o **AIM**
6. Entre em uma partida
